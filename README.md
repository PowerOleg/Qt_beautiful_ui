### Проект демонстрирует навыки динамического построения приложения, использования паттернов проектирования.

###№ Абстрактная фабрика: В конструкторе `MainWindow` создаётся экземпляр фабрики factory = new GreenFactory(this);

- `GreenFactory` — создаёт виджеты в «зелёной» теме с закруглёнными формами.
- `SquareFactory` — создаёт виджеты в «синей» теме с квадратными формами.

###№ Ключевые классы:

- **ESimModel** — модель данных, наследующая `QAbstractTableModel`. Отвечает за хранение и предоставление данных таблице.
- **QTableView** — представление, отображающее данные модели.
- **CheckBoxItemDelegate** — делегат на базе `QStyledItemDelegate`, реализующий CheckBox в 4‑м столбце таблицы. Делегат обрабатывает события мыши для заполнения следующего столбца
- **TableController** — класс, в который инкапсулирована логика добавления/удаления строк в таблицу.
