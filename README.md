Приложение демонстрирует навыки формирования таблицы используя классы: ESimModel, модель с данными - наследник QAbstractTableModel. QTableView - представление таблицы. Класс CheckBoxItemDelegate наследник QStyledItemDelegate чтобы на 4-м столбце нажимался CheckBox.
Справа от таблицы есть кнопки добавить строку по кнопке и по кнопке можно удалить строку таблицы. Действия с таблицей инкапсулированы в класс TableController, что соответствует паттерну Стратегия. 

Реализованны паттерны: Абстрактная фабрика(Abstract Factory). В конструкторе mainwindow.cpp создается объект factory = new GreenFactory(this); factory создает семейство виджетов в одной стилистике, зеленые и круглые. Создав другой экземпляр класса factory = new SquareFactory(this); автоматически создаются виджеты синие и квадратные.
