### Динамически конфигурируемый Qt‑интерфейс: переключение стилей виджетов используя паттерн Abstract Factory и управление данными таблицы через паттерн Strategy

#### Абстрактная фабрика: В конструкторе `MainWindow` создаётся экземпляр фабрики factory = new GreenRoundFactory(this);

- **GreenRoundFactory** — создаёт виджеты в «зелёной» теме с закруглёнными формами.
- **BlueSquareFactory** — создаёт виджеты в «синей» теме с квадратными формами.

#№№№ Реализация паттерна «Команда» для добавления и удаления строк таблицы

- **Кнопка «Отменить действие»** — отменяет последнее выполненное действие (добавление или удаление строки).
- **Кнопка «Повторить действие»** — повторяет отменённое действие, если оно есть в истории.
- **Ограничение истории**: хранится не более 50 последних действий (настраивается в `TableController`).

#### Ключевые классы для работы с таблицей:

- **ESimModel** — модель данных, наследующая `QAbstractTableModel`. Отвечает за хранение и предоставление данных таблице.
- **QTableView** — представление, отображающее данные модели.
- **CheckBoxItemDelegate** — делегат на базе `QStyledItemDelegate`, реализующий CheckBox в 4‑м столбце таблицы. Делегат обрабатывает события мыши для заполнения следующего столбца
- **TableController** — реализует роль контроллера в MVC‑архитектуре. Логика операций с данными (добавление, удаление строк) вынесена в отдельную стратегию, что соответствует паттерну Strategy.
